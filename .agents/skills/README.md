# Coach agent skills

Committed skills for telemetry coaching in this repo.

| Skill | Role |
|-------|------|
| `vre-coach-router` | Route lap/spin/technique questions |
| `vre-collect-evidence` | Build citation-tagged evidence packs |
| `vre-incident-analysis` | Spins / loss-of-control |
| `vre-corner-coaching` | Technique, drills, time loss |
| `vre-explain-dynamics` | Physics / mechanism |
| `vre-teach-answer` | Final WHAT/WHY/HOW response |
| `vre-annotate-replay` | Persist notes on replay bundles |

**Reference docs:** [CONTEXT.md](../../CONTEXT.md), [docs/coach/](../../docs/coach/).

Other skills installed locally via `npx skills` are gitignored.
