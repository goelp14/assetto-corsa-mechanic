# Agent skills in this repo

Only **Virtual Race Engineer coach** skills are committed:

| Skill | Role |
|-------|------|
| `vre-coach-router` | Route telemetry/coaching questions |
| `vre-collect-evidence` | Build citation-tagged evidence packs |
| `vre-incident-analysis` | Spins / loss-of-control |
| `vre-corner-coaching` | Technique, drills, time loss |
| `vre-explain-dynamics` | Physics / mechanism explanations |
| `vre-teach-answer` | Final WHAT/WHY/HOW coaching response |
| `vre-annotate-replay` | Persist notes on replay bundles |

Other skills (brainstorming, vercel-*, python-*, etc.) may exist here locally after `npx skills` installs — they are **gitignored**. See root `.gitignore` and `skills-lock.json` (also ignored).
